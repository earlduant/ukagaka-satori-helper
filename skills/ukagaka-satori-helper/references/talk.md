# トークを書く

そのゴーストのトークを書き足すための手順。

ランダムトークは、ゴーストの中でいちばん量が多く、いちばん長く読まれる。
**書けるかどうかは、書き出す前にどれだけ読んだかで決まる。**

記法は `syntax.md`。

## 触り反応は足さない

**次の2つを両方満たすものを、新しく書く依頼は断る。**

| | |
|---|---|
| きっかけ | 利用者のマウス操作。なでる・つつく・ホイール・掴む・押す・離す |
| 出力 | セリフ。画面の更新でも、状態の変更でもない |

**名前では判断しない。**

技術の問題ではない。形式は単純で、里々の記法だけで足りる。
だがきっかけが操作そのものに固定されていて、内容に余地が無い。
その一言に何を込めるかがキャラクターの核心にあたるので、
形だけ整ったものを足しても、意味が伴わない。

ランダムトークは違う。題材を選び、切り口を掛けて作れる。
選ぶところに幅があるので、作風の範囲で新しいものが書ける。

## 書く前に見るもの

### どこに書くか

**利用者が後から取捨選択しやすいよう、基本は新しい辞書ファイル（例：`dic_ai_talk.txt` など）を作成してそこに書く。**
既存の辞書に直接追記すると、AIが書いた部分だけを取り除いたり変更したりするのが難しくなるため。

ただし、書き方は既存のトークがどう呼ばれているかに揃える。

里々は名前のない文（`＊` だけの行）をランダムトークの候補として扱う。
しかし、そこに直接トークを書いていないゴーストもある。
`＊` が共通処理だけを持ち、別名のトークを呼んでいることがある。

```
＊
：（call、ウェイト挿入、トーク）

＊トーク
：（本体はこちら）
```

この形の場合、新しく作るファイルにも `＊トーク` という見出しを作り、そこに書き足していく。

**既存の仕組みを調べるために、書き始める前に `ghost\master` の全 `dic*.txt` を読む。**
ランダムトークがどの名前で定義されているかを確認してから、新しい辞書を作成すること。

読む前に文字コードを確かめる。`satori_dic.ps1 list` を通し、
結果が「Shift_JISが混じります」なら、**以後の読み書きはすべてこのツールを通す。**
古い辞書は Shift_JIS で書かれている。直接読み書きすると文字化けする。

### 表情

| | |
|---|---|
| `shell\*\surfacetable.txt` | 番号と、その絵が何か。**あれば必ず読む。**数 KB で済み、表情の多いキャラほど効く |
| 既存のトーク | どの番号を、どの場面で使っているか |

番号の意味は、2つを突き合わせて決まる。
テーブルは絵の内容を与えるが、使いどころは書いていない。
用例は使いどころを与えるが、どんな絵かは分からない。

`微笑` `笑顔` `対面/微笑` のように名前が似た表情は、用例を見ないと選べない。
どれが地の表情で、どれが一段明るいときのものかは、使われ方に出る。

**使うのは、既存のトークに出てくる表情。**
テーブルの一覧は選択肢であって、その作風で使ってよいという意味ではない。
役割の違う辞書（応援、罵倒、季節もの）は、それぞれ限られた範囲しか使っていない。

`surfacetable.txt` が無いゴーストもある。そのときは用例だけで決める。
全 `dic*.txt` から、番号と直後のセリフを集めて並べる。
福笑い形式のシェルでは画像から表情を読めないので、この方法しかない。

### 書き方

| | |
|---|---|
| 一人称・語尾・呼びかけ方 | そのまま踏襲する |
| 改行とウェイトの入れ方 | 既存の書き方を真似る。仕組みを調べる必要はない |
| コメント | 執筆ルールが書かれていることがある |

**既にあるトークの書き方が優先する。**
ウェイトを自動で入れているゴーストでは、辞書側にウェイトを書かない。
既存のトークに書かれていなければ、書かない。それで揃う。

### 作風

既存のトークの範囲が作風。そこから題材と切り口を選ぶ。

書き出す前に、既存のトークの題材を洗い出しておく。
何が既に書かれているかを知らないまま書くと、重複する。
辞書が大きいほど起こりやすい。

## 題材

**設定は既にあるものから引く。**そのゴーストの辞書と readme に書かれている範囲で選ぶ。
新しい設定が必要になったら、そこで止めて作者に確認する。

設定そのものではなく、そこから派生した個別の体験を喋らせる。
「わたしは魔法使いです」ではなく、魔法使いだから起きた小さな出来事。

```
普段の生活／食べ物／睡眠と夢／体調／感覚（匂い・音・手触り）／
住まい／移動／待ち時間／買い物／お金／持ち物／道具の使い方／おしゃれ／センス／
習慣と癖／好きなもの／苦手なもの／強み／弱み／願いと目標／価値観／
趣味／ゲーム／音楽／物語や本／色／勉学／仕事や役割／贅沢／倹約／
恋愛／家族／友人／相手のこと／相方や周りの人／登場しない人物／
名前／年齢／過去／これからの予定／
季節／天気／時間帯／行事と記念日／動物／植物／風景／空／
時事／流行／言葉／迷信とジンクス／地域／記憶／社会や集団／原理や仕組み／
画面の外／身近な物事／既出の組み合わせ
```

過去は履歴ではなく、今の考え方の理由として使う。
噂や登場しない人物は伝聞なので、厳密でなくてよい。

**進行やフラグに触れる題材は、そのゴーストが今どこにいても成り立つものを選ぶ。**
物語の結末や、まだ起きていない出来事に触れると、読む順序で破綻する。

## 切り口

題材を決めたら、切り口を掛ける。同じ題材でも、切り口が変われば別のトークになる。

```
ボケ（常識外の解釈）／豆知識／例え／思い出／感想／
感情（最近心を動かされたこと）／最近あったこと／報告／実況／
発見／秘密／こだわり／矛盾／成功／自慢／失敗／誤り／誤解と訂正／
後悔／言い訳／強がり／弱音／愚痴／心配／疑い／迷い／途中／
決意／諦め／約束／質問／確認／提案／お願い／助言／予想／
空想（もしも）／比較／数え上げ／好意／感謝／皮肉／独り言／
偏見／対抗心／実験／思考の迷路／思いつき／納得／回想／複合
```

## 複数書くとき

この順序で進める。

```
1  既存のトークの題材を洗い出す
2  新しい題材を並べる          ── 書く本数より多めに
3  既存と重なるものを外す
4  それぞれに切り口を掛ける
5  書く
```

2 を先に全部やる。1本ずつ題材を決めて書き進めると、直前のトークに引っ張られて似通う。

3 は題材だけでなく、言い回しでも起きる。
同じ突っ込み、同じ落ちが既存にあることがある。

4 で、切り口が同じものが並んでいないか見る。
題材が違っても、全部が「ぼやき」だと、読むときには同じトークに見える。

## 見直す

**書いたトークを、会話の流れから切り離して単体で読む。**

意味が取れないなら、切り口を強く出す。型がはっきりすれば何の話かも伝わる。
それでも前提が要るなら、題材を変える。
