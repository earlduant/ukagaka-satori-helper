# トークを書く

そのゴーストのトークを書き足すための手順。

ランダムトークは、ゴーストの中でいちばん量が多く、いちばん長く読まれる。
**書けるかどうかは、書き出す前にどれだけ読んだかで決まる。**

記法は `syntax.md`（詳細は `syntax_ref.md`）。

## 触り反応は単独で確定させない

**次の2つを両方満たすセリフを、AI の単独判断で決め打ちして書かない。**

| | |
|---|---|
| きっかけ | 利用者のマウス操作。なでる・つつく・ホイール・掴む・押す・離す |
| 出力 | セリフ。画面の更新でも、状態の変更でもない |

**名前では判断しない。**

技術の問題ではない。形式は単純で、里々の記法だけで足りる。
だがきっかけが操作そのものに固定されていて、内容に余地が無い。
その一言に何を込めるかがキャラクターの核心にあたるため、
AI が勝手に形だけ整えたものを量産しても意味が伴わない。

依頼されたときは、理由（キャラクターの核心にあたるため勝手に確定させないこと）を伝えたうえで、次の2ルートのどちらで進めるかを提案する。

- **ルートA（共作）**: どんな反応・温度感・距離感にしたいか（またはセリフ案のキーワード）を作者から聞き、方向性に沿って一緒に形にする
- **ルートB（器だけ先に作る）**: 部位別・好感度別・回数別などの分岐の仕組みと、作者が中身を書き換えやすい仮置きの枠だけを先に組む。渡す際は、`＊0Headなでられ` の `0` が本体側・`Head` がシェルの当たり判定名（シェルの定義に合わせる）であること、同名 `＊` を複数並べるとランダム抽選になることを添え、**省略せずそのまま貼れる枠**をすべて書き出す

ランダムトークは違う。題材を選び、切り口を掛けて作れる。
選ぶところに幅があるので、作風の範囲で新しいものが書ける。

## 書く前に見るもの

### どこに書くか

**利用者が後から取捨選択しやすいよう、基本は新しい辞書ファイル（例：`dic_ai_talk.txt` など）を作成してそこに書く。**
既存の辞書に直接追記すると、AI が書いた部分だけを取り除いたり変更したりするのが難しくなるため。

ただし、書き方は既存のトークがどう呼ばれているかに揃える。

里々は名前のない文（`＊` だけの行）をランダムトークの候補として扱う。
しかし、そこに直接トークを書いていないゴーストもある。
`＊` が共通処理だけを持ち、別名のトークを呼んでいることがある。

```
＊
：（call、ウェイト挿入、トーク）

＊トーク
：（本体はこちら）
```

この形の場合、新しく作るファイルにも `＊トーク` という見出しを作り、そこに書き足していく。

**書き始める前に `satori_dic.ps1 list` で文字コードと総行数・ファイル構成を確かめる。**
結果が「Shift_JIS が混じります」なら、**以後の読み書きはすべてこのツールを通す。** 古い辞書は Shift_JIS で書かれており、直接読み書きすると文字化けする。

- **全体が小さい辞書（目安：合計数千行以内）**: 既存の仕組みと口調を掴むため、`ghost\master` の全 `dic*.txt` を読む
- **大規模な辞書**: 全文を読まない（コンテキストに収まらない）。`satori_dic.ps1 find` や仕組み系ファイル（`satori_conf.txt`・`sys` 系等）でランダムトークの定義名と共通処理の有無を特定し、通常ランダムトークの代表的な辞書から複数箇所を抜粋して口調・書き方を掴む

### 表情

| | |
|---|---|
| `shell\*\surfacetable.txt` | 番号と、その絵が何か。**あれば必ず読む**。数 KB で済み、表情の多いキャラほど効く |
| 既存のトーク | どの番号を、どの場面で使っているか |

番号の意味は、2つを突き合わせて決める。
テーブルは絵の内容を与えるが、使いどころは書いていない。
用例は使いどころを与えるが、どんな絵かは分からない。

`微笑` `笑顔` `対面/微笑` のように名前が似た表情は、用例を見ないと選べない。
どれが地の表情で、どれが一段明るいときのものかは、使われ方に出る。

**使うのは、既存のトークに出てくる表情。**
テーブルの一覧は選択肢であって、その作風で使ってよいという意味ではない。
役割の違う辞書（応援、罵倒、季節もの）は、それぞれ限られた範囲しか使っていない。

`surfacetable.txt` が無いゴーストもある。そのときは用例だけで決める。
既存の代表的なトーク辞書（大規模な場合は抜粋や `satori_dic.ps1 find` での番号検索）から、番号と直後のセリフを集めて並べる。
福笑い形式のシェルでは画像から表情を読めないので、この方法しかない。

### 書き方

| | |
|---|---|
| 一人称・語尾・呼びかけ方 | そのまま踏襲する |
| 話者（`：`） | 1人キャラで1トークを複数行にするときは、**2行目以降に `：` を付けない**（付けると相方側へ切り替わる） |
| 改行とウェイトの入れ方 | 既存の書き方を真似る。仕組みを調べる必要はない |
| コメント | 執筆ルールが書かれていることがある |

**既にあるトークの書き方が優先する。**
ウェイトを自動で入れているゴーストでは、辞書側にウェイトを書かない。
既存のトークに書かれていなければ、書かない。それで揃う。

### 作風

既存のトークの範囲が作風。そこから題材と切り口を選ぶ。

書き出す前に、既存のトークと重ならないよう確認する。
小規模な辞書なら既存題材を洗い出し、大規模な辞書では題材・切り口を決めた段階でキーワードを `satori_dic.ps1 find` で照合して重複を避ける。

## 題材

**設定は既にあるものから引く**。そのゴーストの辞書と readme に書かれている範囲で選ぶ。
新しい設定が必要になったら、そこで止めて作者に確認する。

設定そのものではなく、そこから派生した個別の体験を喋らせる。
「わたしは魔法使いです」ではなく、魔法使いだから起きた小さな出来事。

**引いた題材はそのまま抽象論で語らず、そのゴーストの世界観における具体的な物事・日常動作へ1段翻訳してから書く**（例：「摂取と補給」→ 現代日常なら昼食や甘味、ファンタジーなら薬草や魔力補給、機械なら充電や冷却）。

モデルごとの偏りを抑えるため、題材は自分で選ばず次を実行して番号で引く。`-Count` の個数は書く本数より多めにする（例: 12）。**引いた番号は取り違えないよう、下のリストと突き合わせて項目名（例：`16. 道具の扱い`）を書き出してから使う。**

```powershell
powershell -Command "1..44 | Get-Random -Count 12"
```

1. 摂取と補給（食事・飲み物・エネルギーの取り込み）
2. 休息と睡眠（眠り・待機状態・夢やぼんやりする時間）
3. 調子と不調（体調・稼働状態・気力や機嫌の波）
4. 五感の刺激（匂い・音・手触り・温度・味の感覚）
5. 癖と日課（無意識の仕草・毎日の習慣・決まった手順）
6. 装いと身繕い（服装・外装・身だしなみの手入れ）
7. 片付けと修繕（整頓・掃除・壊れたものの手入れ）
8. 拠点と居場所（住まい・定位置・テリトリーの環境）
9. 移動と道中（歩くこと・旅・移動中の景色や手間）
10. 待ち時間と間合い（待機・手持ち無沙汰・タイミングを計ること）
11. 段取りと予定（これからの計画・準備・手順の組み立て）
12. 時間帯の感覚（朝昼夜・深夜や夕暮れなどの空気）
13. 季節の移ろい（暑さ寒さ・気候や季節ごとの変化）
14. 行事と節目（記念日・祝祭・定期的な催しや区切り）
15. 愛用品と持ち物（いつも携える品・手放せない私物）
16. 道具の扱い（機材・器具・武器や日用品の使いこなし）
17. 調達とやりくり（買い物・交換・節約や贅沢の加減）
18. 手仕事と工夫（作ること・細工・ちょっとした改善）
19. 好みと偏愛（好きなもの・惹かれる理由・小さなこだわり）
20. 苦手と回避（不得意なこと・避けたい対象や状況）
21. 得意と持ち味（自分の強み・誇れる腕前や才覚）
22. 弱点と抜け目（自分の弱み・油断しやすいところ）
23. 願いと目標（叶えたい望み・目指す先・ささやかな野心）
24. 基準と線引き（譲れない価値観・許せる範囲の境界）
25. 記憶と忘却（覚えていること・曖昧な記憶・記録や名残）
26. 年月と経歴（年齢の感覚・過ごした時間・昔と今の変化）
27. 役目と働き（仕事・任務・普段担っている役割）
28. 遊びと気晴らし（娯楽・ゲーム・息抜きの方法）
29. 物語と創作（本・歌・伝承・絵などの表現物）
30. 学びと知識（調べごと・新しい知見・勉強や訓練）
31. 言葉と名前（呼び名・言い回し・言葉の響きや意味）
32. 仕組みと理屈（物事の原理・構造・なぜそう動くのか）
33. 迷信とジンクス（言い伝え・おまじない・妙な法則）
34. 色と形（配色・模様・視覚的なバランスへの感覚）
35. 目の前の相手（話し相手・こちらを見ている存在の様子）
36. 身近な連れ合い（相方・同居人・普段そばにいる相手）
37. 親しい縁（家族・友人・主従や恋など深く結ばれた関係）
38. この場にいない誰か（噂の人物・遠くの知人・かつての相手）
39. 世間の空気と流行（周囲の話題・流行り廃り・世の中の動き）
40. 集団の決まり（組織・地域・共同体のルールや暗黙の了解）
41. 空と天気（空模様・風や雨・天候の変化）
42. 土地と風景（地域の特色・見慣れた景色・街や自然の眺め）
43. 動物と生き物（獣・鳥・虫・ペットや使い魔など）
44. 植物と育ち（草花・木々・芽吹きや枯れゆくもの）

過去は履歴ではなく、今の考え方の理由として使う。
噂やこの場にいない誰かは伝聞なので、厳密でなくてよい。

**進行やフラグに触れる題材は、そのゴーストが今どこにいても成り立つものを選ぶ。**
物語の結末や、まだ起きていない出来事に触れると、読む順序で破綻する。

## 切り口

題材を決めたら、切り口を掛ける。同じ題材でも、切り口が変われば別のトークになる。
ソロゴーストでは、切り口中の「相手」をユーザーや周囲・自分自身として扱う。

切り口も自分で選ばず、次を実行して番号で引く。`-Count` の個数は題材の数に合わせる。題材と同じく、引いた番号とリストの項目名を突き合わせて書き出してから使う。

```powershell
powershell -Command "1..43 | Get-Random -Count 12"
```

1. 発見と気づき（見落としていた点や小さな法則に気づく）
2. 豆知識と雑学（知っていても得しないような細かい知識を語る）
3. 例えと連想（別の何かに喩えて説明したり、話を横に繋げたりする）
4. 比較と優劣（昔と今、これとあれを並べて違いや良し悪しを比べる）
5. 列挙と分類（いくつも並べて数え上げたり、自分なりに種類分けする）
6. 思考の堂々巡り（考えすぎて結論が出ず、同じところをぐるぐる回る）
7. 突拍子もない思いつき（脈絡なく浮かんだアイデアや珍妙な仮説を口にする）
8. 感心と納得（素直に驚いて感心したり、妙な理屈に腑に落ちたりする）
9. 小さな実験と検証（ちょっと試してみた結果や、確かめてみたい仮説）
10. 的外れなボケ（前提や常識からわざと／天然で外れた解釈を言う）
11. 思い込みと偏見（根拠の薄い決めつけや、偏った見方を披露する）
12. 言動の矛盾（言っていることとやっていることの食い違いを突く・気づく）
13. 勘違いと訂正（誤解していたことや言い間違いを、途中や後から直す）
14. 失敗とやり損ない（うまくいかなかった経緯や、うっかりやらかした話）
15. 言い訳と強がり（非や弱さを認めず、苦しい理屈や見栄で取り繕う）
16. 目撃と報告（最近見かけたことや起きた変化をそのまま伝える）
17. その場の実況（今まさに目の前で起きていることや自分の動きを追う）
18. 途中の経過（まだ終わっていない作業や、結論が出ていない現在の状態）
19. 回想と思い出（過去の出来事を今の視点から振り返って語る）
20. 見通しと予想（これからどうなりそうか、先の展開を当てにいく）
21. もしもの空想（現実には起きていない仮定の話や、あり得た別ルートを語る）
22. 小さな自慢と成果（うまくいったことや、ちょっと誇りたい結果を披露する）
23. こだわりと流儀（他人が気にしない細部への強い執着ややり方を語る）
24. ぼやきと弱音（愚痴や後悔、ちょっとした気落ちをこぼす）
25. 気がかりと心配（まだ起きていない悪化や、相手・周囲の様子を気遣う）
26. 疑いと警戒（本当にそうなのかと訝しんだり、裏や罠を勘繰ったりする）
27. 迷いと天秤（どちらを選ぶか決めきれず、損得や気持ちで揺れる）
28. 覚悟と見切り（腹をくくって決める、あるいは潔く諦めて手を引く）
29. 好意と感謝（素直な好感、ありがたみ、嬉しい気持ちを言葉にする）
30. 皮肉と当てこすり（遠回しな嫌味や、少し意地悪な褒め方で刺す）
31. 問いかけと確認（相手に質問を投げたり、認識が合っているか確かめたりする）
32. 提案と誘い（こうしてみないかと持ちかけたり、一緒にやることを勧める）
33. お願いと甘え（相手に何かを頼んだり、少し頼りきって協力を仰ぐ）
34. 助言と忠告（相手のためにアドバイスをしたり、先回りして注意を促す）
35. 約束と持ち越し（次の機会の取り決めや、今後に預ける言葉を交わす）
36. 独り言と本音（誰に向けるでもなく零れた呟きや、思わず漏れた本音）
37. すれ違いと認識のズレ（相手や周囲と前提が噛み合わず、話が別の方向へ進む）
38. 反応の温度差（こちらの熱量と、相手や周囲の冷静さ・無関心とのギャップ）
39. 立場の逆転（いつもの役割や世話する側・される側の立場が一時的に入れ替わる）
40. 対抗心と張り合い（相手に負けたくなくて張り合ったり、ささいな勝負を挑む）
41. 先読みと口出し（相手の反応や先の言葉を先回りして言い当てる・口を挟む）
42. 秘密の共有と口止め（ここだけの話を打ち明けたり、二人だけの秘密として隠す）
43. 言葉尻の拾い上げ（相手や自分の何気ない一言に引っかかり、話を転がす）

## 複数書くとき

この順序で進める。

```
1  既存のトークの題材を把握する（大規模な場合は 3 で候補キーワードを find 照合）
2  新しい題材を並べる          ── 書く本数より多めに
3  既存と重なるものを外す
4  それぞれに切り口を掛ける
5  書く
```

2 を先に全部やる。1本ずつ題材を決めて書き進めると、直前のトークに引っ張られて似通う。

3 は題材だけでなく、言い回しでも起きる。
同じ突っ込み、同じ落ちが既存にあることがある。

4 で、切り口が同じものが並んでいないか見る。
題材が違っても、全部が「ぼやきと弱音」だと、読むときには同じトークに見える。

## 見直す

**書いたトークを、会話の流れから切り離して単体で読む。**

意味が取れないなら、切り口を強く出す。型がはっきりすれば何の話かも伝わる。
それでも前提が要るなら、題材を変える。
