# バルーンの中の表示

バルーンは、文字を1文字ずつ描いていく装置である。
カーソルがあり、そこへ文字が置かれ、置いた分だけカーソルが進む。
ここにあるタグは、すべてそのカーソルか、描かれる文字の見た目を触っている。

ここにあるタグを解釈するのは SSP である。里々の記法は `syntax.md`。

## 確かめられる範囲

**ここに書いてあることは、動かしても確かめられない。**

組み立てた `\_l` の座標が想定した値になっているかは、返った文字列で追える。
その座標で正しく見えるかは分からない。罫線が繋がっているか、枠からはみ出して
いないか、文字が重なっていないかは、画面を見た人にしか言えない。

ここにある形は、実際に表示を確認したものと、SSP の仕様から導けるものである。
そこから外れたものを組み立てたときは、表示の確認を利用者に依頼する。
「動きました」と報告しない。

依頼するときは、何を見てほしいかを具体的に書く（→ `dialogue.md`）。

> 枠が正しく閉じているか、`◯` が枠の中に収まっているかを見てください。
> 崩れている場合は、枠の幅か `\_l` の移動量が合っていません。

## 大きさは実行時に決まる

バルーンの幅・高さ・入る行数・フォント・背景色・拡大率を持っているのは SSP である。
辞書にも、ゴーストのファイルにも書かれていない。

利用者はいつでもバルーンを変えられる。専用のバルーンを同梱していても、
それが使われている保証はない。拡大率も変えられる。

**固定の行数や文字数を前提にした表示を組まない。**
どのバルーンでも崩れないように組むのが既定の方針になる。

`\![change,balloon,…]` で切り替えられるが、利用者の選択を上書きすることになる。

### 形が前提になる画面だけ、推奨バルーンを指定する

ノベルゲーム風の横長ウィンドウのように、特定の形でなければ成立しない場合は、
バルーンを同梱して `descript.txt` に書く。

```
recommended.balloon,バルーン名
recommended.balloon.path,パス        同梱する場合
balloon,バルーン名                    標準で使うバルーン
balloon.syncscale,true                拡大縮小率をゴーストと連動させる
```

それ以外へ切り替えようとすると SSP が強い警告を出す。
利用者の選択を制限するので、形が本当に前提になる場合だけ使う。

### 値が要るなら、ツールで自ら取る

SSP のプロパティシステムから取れる（→ `testing.md` の「SSP にしか無い情報を取る」）。
**まず取りに行く。**動いていなければ、ツールがそう言って終わる。

| | |
|---|---|
| `currentghost.balloon.scope(ID).lines` | 収まる行数 |
| `～.lines.initial` | 収まる行数。文字描画開始点を考慮したもの |
| `～.validwidth` / `～.validheight` | 文字描画に使える幅・高さ |
| `～.validwidth.initial` / `～.validheight.initial` | 同上。文字描画開始点を考慮したもの |
| `～.char_width` | 半角文字の幅 |
| `～.basepos.x` / `～.basepos.y` | 文字描画開始点。`\_l` のピクセル座標の原点 |
| `～.vertical` | 縦書きなら 1 |
| `～.scaling` | 実効拡大率。`横,縦` の2値（`100,100`）。小数が出ることがある |
| `～.background.color` | 背景色。`R,G,B` |
| `～.num` | バルーンの ID |

`ID` はスコープ番号（`\0` なら 0）。

1行に何文字入るかを出すなら、先に `vertical` を見る。
横書きなら `validwidth`、縦書きなら `validheight` が「1行の長さ」にあたる。

## カーソルとウェイト

バルーンの表示には、独立した2つの仕組みがある。混ぜて考えない。

| | |
|---|---|
| カーソル | 次の文字を置く位置。`\_l` `\n` が動かし、`\c` が戻す |
| ウェイト | 文字が出るまでの待ち時間 |

カーソルはスコープごとに持つ。`\0` と `\1` は別のバルーンで、
それぞれが自分の位置を覚えている。

ただし、両方が同時に動くことはない。
さくらスクリプトは1本の列として、先頭から順に実行される。

```
\0test。\w5\1テスト。
```

```
t を出す → 設定値ぶん待つ → e を出す → 設定値ぶん待つ →（略）
→ 「。」を出す → \w5 で 250ms 待つ → スコープが \1 へ移る
→ 「テ」を出す → 設定値ぶん待つ → …
```

片方が喋っている間、もう片方は止まっている。
掛け合いに見えるものも、交互に1文字ずつ出ている。

例外は `\_s` で囲んだ区間だけである
（→ [`\_s` ── 両方のバルーンに同時に出す](#_s--両方のバルーンに同時に出す)）。

### ウェイトも2種類ある

**この2つは別に効く。片方を止めても、もう片方は残る。**

| | |
|---|---|
| 暗黙 | SSP の設定。1文字を表示するごとに待つ時間。利用者が変えられる |
| 明示 | ウェイトタグ。`\w9` `\_w[…]`。書かれた位置で、書かれた分だけ止まる |

暗黙のほうは速さが環境によって違う。特定の速度を前提にした演出を組まない。

里々が句読点の直後に自動挿入するのは、明示のほう（`\_w[…]` というタグとして入る）。
止め方は `syntax.md`。

`\_q` が 0 にするのは暗黙のほうだけである（→ [`\_q` ── 文字送りを 0 にする](#_q--文字送りを-0-にする)）。

#### 暗黙のウェイトは辞書から変えられる

```
\![set,balloonwait,0.5]    0〜100。1 で等倍。小数可
\![set,balloonwait,150%]   0〜10000。100 で等倍。整数のみ
\![set,balloonwait,10ms]   0〜10000。1文字あたりの待ち時間をミリ秒で直接指定
\![set,balloonwait,0]      常時即時表示
\![set,balloonwait]        既定値に戻す
```

スクリプトが終わると既定へ戻る。次のトークには持ち越さない。

`\_q` は 0 にすることしかできない。遅くしたい、少しだけ速くしたいならこちら。

### 行の高さは2種類ある

| | |
|---|---|
| `1em` | 文字の高さ。タグを書いた時点の文字サイズが基準 |
| `1lh` | 行の高さ。`1em` ＋ 行間 |

`\n` の改行は `1lh` ぶん進む。`1em` ぶんしか進めなければ、行間はできない。

この差が見た目に出る。罫線を `\n` で送ると行間のぶんだけ隙間が空き、縦線が
途切れて見える。`\_l[@0,@1em]` で送れば繋がる（→ [罫線で枠を描く](#罫線で枠を描く)）。

## 置く

### `\_l[x,y]` ── カーソルを動かす

指定できる形は5つある。X と Y で別の形を使ってよい。

| 書き方 | 意味 |
|---|---|
| `\_l[100,50]` | ピクセル。文字描画開始点（横書きなら描画範囲の左上）からの座標 |
| `\_l[@-50,@20]` | `@` を付けると現在位置からの相対移動 |
| `\_l[3em,1.5em]` | 文字高さが基準。小数可 |
| `\_l[0,2lh]` | 行高さ（`1em` ＋ 行間）が基準。小数可 |
| `\_l[50%,0]` | パーセント |
| `\_l[centerx,centery]` | バルーン画像の中央。**これだけ基準が違う**（文字描画開始点ではない） |
| `\_l[,]` | 省略すると移動しない。両方省略すると無効果 |

符号は、左右は正が右・負が左、上下は正が下・負が上。

単位の使い分け

| | |
|---|---|
| 文字を並べる | `em` か `lh`。書体や文字サイズが変わっても崩れにくい |
| 図形を描く | ピクセル。`em` では 2px 刻みのような細かい制御ができない |

1つの式の中で混ぜてよい。`\_l[13.5em,2.5em]` で列を揃え、`\_l[231,38]` でバーを引く。

**`\_l` の直後、行揃えが左揃えにリセットされる。**
`\f[align]` を使っているなら、`\_l` のたびに指定し直す。

`\_l` で移動した後に `\f[align,center]` を指定すると、`\_l` の X 座標ぶん
インデントされたものとして中央揃えされる。移動していない行の中央とは合わない。

### `\n` ── 改行

| | |
|---|---|
| `\n` | 1行ぶん送る |
| `\n[half]` | 半行 |
| `\n[150]` | パーセント指定。1行半 |
| `\n[-250]` | 負の値で戻る |
| `\n[0]` | **縦に動かないが、改行はした扱いになる** |

最後の `\n[0]` が効くのは、行揃えが「意図的な改行が来るまで」しか続かないためである
（→ [`\f[align]`](#falign--行揃え)）。

### `\f` ── 文字の見た目

| | |
|---|---|
| `\f[color,#FF0000]` | 文字色 |
| `\f[color,disable]` | 無効表示。灰色になり、へこんだように見える。選べない項目に使う |
| `\f[underline,true]` | 下線 |
| `\f[strike,true]` | 取り消し線 |
| `\f[outline,true]` | 白抜き |
| `\f[height,20]` | 文字サイズ。`\f[height,+3]` `\f[height,200%]` も可 |
| `\f[align,…]` | 行揃え（→ 次項） |
| `\f[valign,…]` | 縦の揃え。`top` / `center` / `bottom` |
| `\f[default]` | バルーン属性をすべて既定へ戻す |

**色を固定しない。**バルーンの背景色は利用者が選ぶもので、白背景とは限らない。
`#FFFFFF` を指定すると、白いバルーンでは読めなくなる。
色で区別したいなら、`disable` や `underline` のように背景に依存しない指定を使う。

効果は `\f[…,default]` を書くか `\e` に達するまで続く。別のスクリプトには持ち越さない。

`align` と `valign` はリセットのされ方が逆である。

| | |
|---|---|
| `align` | `\n` や `\_l` で左揃えに戻る |
| `valign` | **`\n` でも `\_l` でも戻らない。**明示的に戻す |

### `\f[align]` ── 行揃え

`left` / `center` / `right`。次の「意図的な改行」（`\n` や `\_l`）まで影響する。

行の途中で変えると、すでに出ている文字も一緒に動く。

```
\f[align,right]まだ継続。\f[align,default]ここでキャンセル。
```

「まだ継続。」は右寄せで表示されている。その後 `\f[align,default]` が読まれた瞬間、
同じ行の文字列全体が左へ移動する。1文字ずつ表示されるため、これは画面上で
文字が横に飛ぶ動きとして見える。

**行揃えの変更は、行の先頭でだけ行う。**

`\_q` で囲んでも解決しない。最後の状態だけが見えることになり、
行の先頭で一度指定したのと同じ結果になる。

同じ行に左寄せと右寄せを混ぜる

「次の意図的な改行まで」という仕様を使い、縦に動かない改行を挟む。

```
\f[align,right]\q[×,OnClose]\n[0]\f[align,default]メニュー
```

1. 右寄せで `×` を描く
2. `\n[0]` で、縦には動かないまま「改行した」ことにする
3. 左揃えに戻して「メニュー」を描く

見た目は1行のまま、両端に別のものを置ける。閉じるボタンを持つメニューはこの形になる。

### `\_b` ── 画像

**2つの系統がある。混同すると位置が合わない。**

| | |
|---|---|
| `\_b[ファイル,inline]` | 1文字としてテキスト行の中に置く。カーソルが進む |
| `\_b[ファイル,x,y]` | 座標に貼る。カーソルは動かない。画像は文字の下 |

基準フォルダは `ghost/master`。相対パスで書く。

`inline` の画像は `\c[char]` で1文字として数えられる（→ [`\c[char]`](#cchar数値--文字数で消す)）。

透過・切り出し・文字の前面への配置はオプションで指定する。引くこと。

`\__q[ID,…]` で囲めば、画像がそのまま選択肢になる。
アイテム一覧・図鑑・選択パネルは、画像を並べてこれで囲むことで作る。

### 罫線で枠を描く

```
＠サイコロ表示３
┏━━━┓\_l[@-5em,@1em]φ
┃◯　　┃\_l[@-5em,@1em]φ
┃　◯　┃\_l[@-5em,@1em]φ
┃　　◯┃\_l[@-5em,@1em]φ
┗━━━┛\_l[@0,@-4em]
```

**`\n` で改行しない。**行間ぶんの隙間が空き、縦の罫線が破線のように途切れる
（→ [行の高さは2種類ある](#行の高さは2種類ある)）。
`\_l[@-5em,@1em]` は「左へ5文字、下へ1文字」で、次の行の先頭へ戻す動きにあたる。

枠の横幅と移動量が対応している。`┏━━━┓` は5文字なので `@-5em`。
枠の幅を変えたら、移動量も変える。

最後の `\_l[@0,@-4em]` は4行ぶん上へ戻している。図の右や元の位置から本文を続けるため。

日本語の等幅フォントを前提にしている。

`em` は文字の高さが基準であって、幅ではない。幅の揃わないフォントでは、
枠の文字数と移動量が対応しない。バルーンの既定フォントが等幅とは限らない。

さらに、罫線（`┏` `━` `┃`）はフォントによって幅が変わる。
日本語フォントは全角幅で描き、欧文フォントは半角幅で描く。
**欧文フォントでは移動量が倍ずれる。**

どうしても必要なら、その区間だけ指定して戻す。

```
\f[name,ＭＳ ゴシック]（表示処理）\f[name,default]
```

戻し忘れると `\e` まで続く。

ただし SSP 本体設定でバルーンフォントを上書きしていると、この指定は効かない。

| 併用するもの | |
|---|---|
| `φ` | 里々が行末に入れる改行を止める（→ `syntax.md`）。`＠` で書くときに要る |
| `\_q` | 1文字ずつ表示されるのを止める。組み上がる過程を見せない |

#### 枠が要るだけなら、囲みの形をした文字を使う

`【1】` `［A］` のように、1文字で囲みになっている文字がある。

位置指定が要らない。行に並べるだけで、フォントにも環境にも依存しない。
枠を組み立てる必要があるのは、中に複数行を入れるときだけである。

画像（`\_b`）で枠を用意する手もある。フォントに一切依存しない。

## 消す

### `\c` ── 全部消す

現スコープのバルーンの文字をすべて消し、カーソルを初期位置（左上）へ戻す。
最もよく使う。

### `\c[line,数値]` ── 行で消す

カーソル位置から指定行数ぶん消す。`\c[line,数値,開始位置]` で開始位置も指定できる
（0オリジン。1行目なら 0）。

「行」の数え方に癖がある。

- `\_l[x,y]` `\n` `\n[half]` `\n[パーセント]` で区切られたものが1行
- 中身のない行は行と数えない。`\n\n\n` と続けても、実際に文字のある行まで遡る
- 例外は `\_l[x,y]`。これで区切られたものは、中身が無くても1行と数える

消した後、カーソルは残った行の末尾に戻る。そのまま続きを書ける。

### `\c[char,数値]` ── 文字数で消す

**表示されている位置ではなく、スクリプト内の出現順で数える。**
`\c[char,数値,開始位置]` で開始位置も指定できる。

ここが直感と合わない。バルーンのどこに見えているかは無関係で、
さくらスクリプト文字列を先頭から数えた順番が使われる。

さらに、`\_b[…,inline]` で貼った画像も1文字として数えられる。

里々は出力に自動でウェイトタグを挿入する（→ `syntax.md`）。
書いた辞書と、SSP が受け取る文字列は同じではない。
書いた文字だけを数えても合わない。

`\c` や `\c[line]` で足りるなら、そちらを使う。

### `\C` ── バルーンを閉じさせない

スクリプトの先頭に置くと、直前に表示したバルーンの内容に追記する。
置かなければ、バルーンは一度閉じて開き直す。

**まだ喋っている最中に `\C` で応答すると、それが終わるまで表示されない。**
反応が遅れることの帰結は `capabilities.md`「実行の途中には手を出せない」。

イベントをまたぐたびに閉じて開き直すと、画面が点滅する。
メニュー、一覧、ページ送りのように同じ画面を何度も描き直す UI は、すべてこの形で書く。

```
\C\c（新しい内容）
```

`\C` でバルーンを保持したまま、`\c` で中身だけ入れ替える。

`\C` はスコープを `\0` に戻す。ただしバルーンの状態は前回の最後が引き継がれる。

#### `＠` で受ける

`＊` は先頭にサーフェス指定などを自動で挿入するため、**`\C` を本当の先頭に置けない。**

`＠` には自動挿入が無い。イベントを `＠OnEventId` の形で受ければ、それで済む。

```
＠OnAnchorSelect.URL
\C\0\j[（Ｒ０）]
```

`＊` でなければならない場合だけ、`＄スクリプトの一番頭` を使う。

```
＊OnAnchorSelect.URL
＄スクリプトの一番頭	\C
\0\j[（Ｒ０）]
```

**これは一度使われると消える。**毎回のトークで使うなら、そのたびに設定し直す。

`\C` に限らず、先頭でなければ効かないタグはすべて同じ扱いになる。

## `\_q` ── 文字送りを 0 にする

次の `\_q` か `\e` まで、1文字ごとの待ち時間を 0 にする。囲んで使う。
`\![quicksection,true]` / `\![quicksection,false]` は同じことを開始・終了で指定する形。

図やメニューを組み立てるときは、組み上がる過程を見せないために囲む。

**止まるのは暗黙のウェイトだけである。**`\w9` や `\_w[…]` が入っていれば、
`\_q` の中でもそこで止まる（→ [ウェイトも2種類ある](#ウェイトも2種類ある)）。

里々の自動ウェイトは句読点の直後に入る。`\_q` の中には挿入されない。
止め方（`φ`、`＄自動挿入ウェイトタイプ`）は `syntax.md` にある。

---

## `\_s` ── 両方のバルーンに同時に出す

次の `\_s` か `\e` まで、メッセージを両方のバルーンに表示する。囲んで使う。
`\_s[0,2,3]` と書くと、指定した ID のスコープだけが対象になる。

同じ文字列が同時に出る。別々のことを喋らせるものではない。

## 中断させない

### `\t` ── 割り込ませない

マウス系などのイベント通知を行わない。クリックや時報でトークが中断されなくなる。

**トグルではない。`\t` を再度書いても解除されない。**

解除されるのは次の2つ。

| | |
|---|---|
| スクリプトブレーク | 選択肢を選ぶ、バルーンのダブルクリックによる中断 |
| `\e` | スクリプトの終わり |

途中で解除したいなら、`\![raise,イベント名]` で一度スクリプトを終わらせ、
別のイベントに移る。

里々は各トークの末尾に `\e` を付ける。したがってトークが変われば解除される。
選択肢を選んだ後のトーク、名前を入力した後のトークには、もう一度書く。
`＞` でジャンプした先は同じトークの続きなので要らない。

```
＊大事なトーク
\t\*：これは全部読んでほしい。
＿○大事な選択肢

＊○大事な選択肢
\t\*：ここも全部読んでほしい。
＞続き

＊続き
：＞の飛び先には要らない。同じトークの続きなので解除されていない。
```

### `\*` ── 選択肢を待たせる

そのスクリプトの選択肢がタイムアウトしなくなる。
スクリプト中のみ有効で、選択肢より後ろに書いても効く。

選択肢が無ければ何も起きない。迷ったら書いておく。

#### 時間を変える

```
\![set,choicetimeout,3000]    3秒。単位はミリ秒
\![set,choicetimeout,0]       タイムアウトしない。-1 も同じ
\![set,choicetimeout]         既定へ戻す
```

`\*` と同じく、そのスクリプト中のみ有効。選択肢より後ろに書いても効く。

カウントはトークの表示が全て終わってから始まる。
文が長ければ、その間は減らない。

時間内に選ばれなければ `OnChoiceTimeout` が発生する。
`（Ｒ０）` にタイムアウトしたスクリプトが入る。

### 記録は完了時にしか取れない

`\t` と `\*` を置いても、**ダブルクリックによる中断は防げない。**
「最後まで読まれた」ことを記録したいなら、トークの末尾で `\![raise]` を発火させ、
その先で記録する。

```
＊大事なトーク
\t\*：……という話。\![raise,OnBigTalkDone]
```

途中で中断されれば `\![raise]` に到達しないので、フラグは立たない。
**トークの先頭で記録すると、読まれていなくても立つ。**
