## 評価モデル

全角括弧 `（）` が里々の唯一の評価単位。内側から評価され、結果が構文として読み直される。

```
（アイテム（C0））             内側の（C0）が 3 に展開され、（アイテム3）になる
（split（バイト値，１）（Ｒ０）（バイト値，１）-）   0x01 に展開されてから区切りとして読まれる
```

- **展開対象と解決順**: `1. 関数` → `2. 単語群（＠）` → `3. 文（＊）` → `4. 変数（Ｒ０・Ａ０ 等の参照値含む）` → `5. 数字（サーフェス指定）` → `6. 情報取得変数（組み込み名）`。空の `（）` はランダムトーク、どれにも該当しなければ文字のまま残る（特殊変数の既定値は代入するまで読めない）
- **引数区切り**は `,` `、` `，` `､` `0x01` の5種。1回の呼び出しで最初に出現した1種類だけに固定される
- 括弧の中身を展開した後の文字列で区切る（ただし遅延評価5関数 `when` `whenlist` `times` `for` `while` は展開前の文字列で数える）
- 評価されるのは `（）` だけ。評価中はさくらスクリプトのタグ（`\![embed,…]` 等）もただの文字で、里々が文字列を返した後にベースウェア（SSP）が解釈する
- **エラーは出ない**。未定義の括弧は文字のまま残り、型検査も引数数検査も行われない

## 定義

行頭の全角 `＊`（文）または `＠`（単語群）から、次の `＊`／`＠` までが1つの定義。先頭から最初の `＊`／`＠` までは無視される。

| | `＊`（文） | `＠`（単語群） |
|---|---|---|
| 単位 | 定義全体で1つのトーク | 1行が1候補（括弧が閉じるまでを1行と数える） |
| 同名の定義 | どれか1つが選ばれる | 候補が合算される |
| 改行・スコープ | 改行が `\n` になり、先頭に `\0`/`\1` とサーフェスが自動挿入されうる | どちらもされない |
| 行頭記号・`：` | 本文で有効 | **無効**（文字として出る）。働くのは `（）` と `＃` のみ |

- **採用条件**は定義名の後ろに**タブ**で区切って書く（省略時は `1`）。偽なら候補から外れ、全候補が偽なら 204 になる
- ユーザ関数（`（call,…）`）の呼び先は **`＠` にする**。`＊` にすると自動挿入された改行やスコープが戻り値に混ざる
- **`＠` に処理を並べて書くと1行しか実行されない**。複数処理は `（nop,…）` の1括弧に収める
- 行末に `φ` を置くと次の行と繋がり、1候補として扱われる

## 記号・話者・全角半角

### 行頭記号と行中記号

| 位置 | 記号 | 役割 |
|---|---|---|
| 行頭のみ | `＊` `＠` | 定義開始（文／単語群） |
| | `＄変数<TAB>値` / `＄変数＝式` | 変数代入（タブは計算なし、`＝` / `=` は計算あり） |
| | `＞ジャンプ先<TAB>条件` | 条件が真ならそのトークへ移動（条件省略で無条件） |
| | `＿選択肢名<TAB>行き先` | 選択肢を出す（行き先省略時は選択肢名と同名へ） |
| | `≫文字列` | あいまい検索ジャンプ（主にコミュニケート用） |
| | `→` | 同時起動中の他ゴーストへ話しかける |
| 行のどこでも | `＃` | 行末までコメント |
| | `：` | セリフ。書くたびに本体（`\0`）と相方（`\1`）が切り替わる |
| | `<頭文字>：` | `characters.ini` があるときのみ、指定キャラへ切り替える |

- **`＊` の本文は相方側（`\1`）から始まる**。セリフは必ず `：` か `\0`/`\1` から書き始める（`：` を書かないと `\1` 側に出る）
- **`＊` の中に処理だけの行（`（nop,…）` 等）を裸で置かない**。本文の1行と数えられ、応答に `\1` と改行 `\n` が混入する。処理は `：` の行の中に書くか、**`＄_捨て<TAB>（nop,…）`** のように `＄` 行に書く（`＄` 行は改行を出さない）
- `＞` でジャンプした先、または `\x`（クリック待ち消去）の直後は `\0` に戻る（`\x[noclear]` では戻らない）
- 上に行を足すと後続の `：` の話者がすべて反転するため、話者を固定したい箇所は `\0` `\1` を直接書く（`＠` 内でも `\0` `\1` を使う）
- **既存箇所は辞書の記法に合わせる**: 分岐（`＞` と `when`）、繰り返し（`＞` と `loop`/`times`/`for`/`while`）、代入（`＄<TAB>` と `set`、計算有無に注意）、選択肢（`＿` と `\q`）は同じ処理を書ける。既存部分の修正はその辞書の書き方に揃え、新機能で未出の関数を使うのは構わない

### 全角と半角の厳密差

里々は全半角を自動正規化しない。

| 要素 | ルール |
|---|---|
| 行頭記号・`＃`・`：`・評価括弧 `（）` | **全角のみ**（末尾を半角 `)` にすると括弧が閉じず、後ろの定義を飲み込む） |
| `（変数「○○」の存在）` 等の「」・乱数範囲 `～` | **全角のみ**（`""` や波ダッシュ `〜` 等は誤動作しエラーが出ない） |
| 組み込み関数名 | **半角小文字のみ**（`WHEN` や `ｗｈｅｎ` は展開されない） |
| 演算子・代入の `＝`・サーフェス数字 `（５）`/`（5）`・`（Ｒ０）`/`（Ａ０）`/`（Ｓ０）`/`（Ｃ０）` | **全角・半角どちらも可**（英字は大文字のみ） |
| 上以外の組み込み変数の番号 | **半角のみ**（`（サーフェス0）` は可、`（サーフェス０）` は不可） |
| 変数名・トーク名・単語群名 | 書いたとおりに区別（`＄Ａ` と `＄A` は別物） |

## 変数・代入・真偽

- **未定義の変数を参照しても空にならない**。`（変数名）` がそのまま表示される。有無は `（変数「名前」の存在）` で確かめる
- **代入3種の違い**:

| 書き方 | 計算 | 未定義変数の扱い | 用途と注意 |
|---|---|---|---|
| `＄名前<TAB>値` | しない | そのまま文字 | 文字列・外部入力の保存はこれ（計算されない） |
| `＄名前＝式` | する（全角数字で返る） | `0` とみなす | 簡単な加算・数式。`＝` 前の空白は無効 |
| `（set,名前,値）` | **数字・`+`・`-` 始まりだけ計算** | 式が文字のまま格納される（`calc` は変数名の一部が混ざる） | 処理の中での代入。日付文字列等も計算されるため注意 |

- **システム値**: `（Ｒ０）`…（イベントの Reference）、`（Ａ０）`…（`call` 引数）、`（Ｓ０）`…（`split` 等戻り値）、`（Ｃ０）`…（ループカウンタ）。**`Ｃ` の番号だけ「入れ子の深さ」**（`Ｃ０` が内側、`Ｃ１` が1つ外側）。これらを自作変数名に使わない
- **真偽の決まり方**: 括弧展開 → 式計算 → 全角数字を半角化 → 先頭から数値として読める部分を読む（C の `strtol` 相当）→ **0 以外なら真**。**「空でなければ真」ではない**（`"さくら"` は `0` になり偽。小数の `"0.5"` も `0` で止まり偽）

## 機械検査で拾えない致命的な罠

構文ミス（`＝` 前の空白、タブ代入の式、行頭 `[`、括弧内の半角スペース字下げ等）は `satori_lint.ps1` が行番号と直し方付きで検出する。ただし **全角 `（` の閉じ忘れ（または半角 `)` の誤記）** は後ろに `）` があると次の `）` まで定義を飲み込んで黙って 204 になるため（lint 無しでコード案を出す際も必ず括弧対応を確認する）、以下と合わせて書く時点で避ける。

| 罠 | 要点 | 詳細（`syntax_ref.md` 等） |
|---|---|---|
| **分岐・選択で両方の枝が実行される** | `if` `iflist` `unless` `switch` `nswitch` `choice` は全引数を先に評価する。処理（`set` 等）を書く枝は必ず **`when` / `whenlist`** を使う | `syntax_ref.md`「枝を選ぶ関数の多くは、両方の枝を実行する」 |
| **遅延評価関数に括弧生成の区切り文字を渡さない** | `when` `whenlist` `times` `for` `while` に `（バイト値,1）` で区切りを作ると遅延判定が壊れ、全枝実行や空カウンタループになる | `syntax_ref.md`「展開を遅らせる関数に、括弧で作った区切り文字を渡さない」 |
| **数字・`+`・`-` 始まりの引数は渡す前に計算される** | `090-1234-5678` や `2026-09-23` を `set` / `join` / `call` に直接渡すと `calc` される。回避は **`vncall`** で変数名を渡すか `＄<TAB>` で代入 | `syntax_ref.md`「数字で始まる引数は、渡す前に計算される」 |
| **引数区切りの誤爆** | 値や `\q` 内の `,`、あるいは選択肢を含むトーク内の `0x01` で引数が割れる。`＄引数区切り追加` や `vncall` で防ぐ | `syntax_ref.md`「引数区切りの誤爆」 |
| **外部文字列は関数に渡すと展開される** | `（Ｒ０）` 等の保護 `φ` は関数引数にした瞬間に外れ、中の全角 `（）` が実行される。区切りを `0x01` にして先に全角括弧を半角へ潰す | `syntax_ref.md`「外部から来た文字列は、関数に渡した時点で展開される」 |
| **名前空間共有と内蔵イベント上書き** | 変数・単語群・トーク・数字（サーフェス指定）は名前空間を共有する。また `OnSecondChange` 等の内蔵イベント名を定義すると内蔵処理が止まる | `syntax_ref.md`「変数・単語群・トークは名前空間を共有する」・`internals.md`「一部のイベントは里々が処理している」 |
| **未知の文字列を `==` で比べない** | 対象に `-` や `!` 等があると式として解釈され壊れる。`（equal,…）` または `（compare,…）` を使う | `syntax_ref.md`「未知の文字列を == で比べない」 |
| **小数は `calc_float` 内だけで扱う** | 通常の条件式や `＝` は小数を扱えない。比較時は `（calc_float,(A)>B）` のように先頭を `(` にする | `syntax_ref.md`「小数は calc_float の中だけで扱う」 |
| **同じ採用条件は1回しか評価されない** | 同名定義で記述が同一の採用条件（`（乱数0～1）` 等）は全候補で結果が共有される | `syntax_ref.md`「同じ採用条件は1回しか評価されない」 |

## 出力の自動加工

括弧をすべて展開し終えた後の文字列に対して、里々が順に行う加工。

| 段階 | 内容 | 詳細 |
|---|---|---|
| 1. 読込時置換 | `replace.txt`（辞書読込時・括弧展開前） | `internals.md`「置換ファイルのタイミング」 |
| 2. 改行・話者・先頭 | `＊` 本文の改行→`\n`、`：`→`\0`/`\1`、先頭サーフェス自動挿入 | `internals.md`「サーフェスの自動挿入」 |
| 3. 括弧・選択肢 | `（５）`→`\s[5]`、`＿`→`\q[…]`（必要に応じ ID へ 0x01 埋め込み） | `internals.md`「選択肢の ID 書き換え」 |
| 4. ウェイト・終端 | 句読点後に `\_w[…]` 自動挿入（`\_q` 内除く）、末尾改行除去＋`\e` 付加 | `syntax_ref.md`「自動で入るウェイト」「ウェイトを止める」 |
| 5. 出力直前置換 | `replace_after.txt`（括弧展開後・もう展開されない） | `internals.md`「置換ファイルのタイミング」 |

- `φ` を直前に置くと、その1文字／1括弧に対する自動処理（括弧展開、改行、自動ウェイト、`replace_after.txt` 置換）を止められる（`syntax_ref.md`「自動処理を止める記号 φ」）
