## 定義・括弧の細部

### 先頭に挿入されるスコープとサーフェス

応答の先頭に `\1\s[…]` が自動で入る。入るのは、そのイベントで最初に選ばれた `＊` のときだけ。`＞` でジャンプした先や、`（）` で呼んだ `＊` では入らない。

挿入される中身は `＄デフォルトサーフェス0` `＄デフォルトサーフェス1` の値。トークの先頭でサーフェスを指定すると、`\0` 側は挿入されない。

```
：あ           → \1\s[10]\0あ
：（５）あ      → \1\s[10]\0\s[5]あ      デフォルトサーフェスは入らない
：\s[5]あ      → \1\s[10]\0\s[5]あ      さくらスクリプトで書いても同じ
```

トークが終わってしばらく後にも同じものが挿入される。`＄会話時サーフェス戻し<TAB>無効` でどちらも止まる。詳細は `internals.md`「サーフェスの自動挿入」。

### 括弧の中の空白

**字下げはタブで行う**。括弧の中で無視されるのは、改行と、行頭のタブだけ。半角スペースは無視されず名前や引数に混ざる。

```
（join
	,-
	,あ
	,い
）            → あ-い

（join
    ,-
）            → （join    ,-） がそのまま出る
```

**条件式の中だけは空白が無視される**（`when` 第1引数、`＞` の条件、採用条件、`calc`）。関数の引数は文字列としてそのまま渡る（`（equal,あ ,あ）` は `0`）。

### 返る値の字種は、こちらでは決められない

| 書き方 | 返る |
|---|---|
| `＄カウンタ＝1＋2` | `３` 全角 |
| `（calc,1+2）` | `3` 半角 |

組み込み変数は変数ごとに違う（以下は代表例。残りは仕様書で引く）。

| 全角で返る | 半角で返る |
|---|---|
| `（現在年）` `（現在月）` `（現在日）` `（現在時）` `（現在分）` `（現在秒）` | `（Ｒの数）` `（Ｓの数）` |
| `（起動秒）` `（累計秒）` `（最終トークからの経過秒）` `（time_t）` | `（サーフェス0）` `（文「○○」の数）` |
| `（単語群「○○」の数）` `（起動しているゴースト数）` | `（変数「○○」の存在）` などの 0／1 |

乱数は書いたほうに合わせて返る（`（乱数0～9）` → `3`、`（乱数０～９）` → `７`）。数値比較・計算ではどちらも同じに扱われる。表示を揃えるなら `（zen2han,…）` `（han2zen,…）` を通す（英数字をまとめて変換する）。

## 名前が決まっている変数

用途が2種類ある。どちらも自作変数と同じ名前空間にあり、同名を付けると動作が変わる。以下は代表例で、全量は「[一覧は里々の仕様書から引く](#一覧は里々の仕様書から引く)」から引く（仕様書では特殊変数を「システム変数」、情報取得変数を「組み込み名」と呼ぶ）。

### 情報取得変数

| 変数 | 返るもの |
|---|---|
| `（現在年）（現在月）（現在日）（現在曜日）（現在時）（現在分）（現在秒）` | 日付と時刻。曜日は「日」「月」…の1文字 |
| `（time_t）` | UNIX 時刻。Mc201-11 以降は符号なし 32bit、それより前は符号付き 32bit |
| `（起動時）（起動分）（起動秒）` `（累計時）（累計分）（累計秒）` | 今回の起動からの経過時間と、累計の起動時間 |
| `（起動回数）` | 「SHIORI が読み込まれた回数」。ネットワーク更新や辞書の読み直しでも増えるため、`＝＝` 判定は飛び越えることがある。`＞＝` で比べるか起動イベントで自分で数える |
| `（最終トークからの経過秒）` | 直前のトークからの秒数 |
| `（乱数1～10）` | 範囲内の整数 |
| `（サーフェス0）（サーフェス1）` | 現在のサーフェス番号 |
| `（文「○○」の存在）（単語群「○○」の存在）（変数「○○」の存在）` | 1 か 0 |
| `（文「○○」の数）（単語群「○○」の数）` | 候補の数。`＊` は定義1つが1候補、`＠` は1行が1候補（同名定義の合計） |
| `（ID）` | いま処理しているイベント名 |
| `（Sender）（Charset）` | リクエストのヘッダ |
| `（Status）` | いまの実行状態（下記） |
| `（里々のバージョン）` | 例：`phase Mc171-4` |
| `（pwd）` | `satori.dll` のあるフォルダ。末尾に `\` が付く |
| `（本体の所在）` | ベースウェアのフォルダ |
| `（起動しているゴースト数）（隣で起動しているゴースト）` | 同時起動の状況 |
| `（予約トーク数）` | `＄次のトーク` で予約されている数 |
| `（選択ＩＤ）（選択ラベル）（選択番号）` | 直前に選ばれた選択肢（下記） |

### テスターでは本物の値が返らないもの

ベースウェアが持つ情報は、テスターでは展開されないかテスターが作った値が返る（→ `testing.md`「確かめられないこと」）。起動中の SSP・里々からは `Get-GhostInfo.ps1` で取れる。

- **返る値を決め打ちした分岐を書かない**
- 取れなかったとき（空や失敗時の値）でも崩れない形にする

### `（Status）` ── いまの実行状態

SSP が送ってくる SHIORI/3.0 Status ヘッダをそのまま返す（空なら空）。よく使う値は `internals.md`「（Status）の値」。

- **複数あるときはカンマでつながる**。`==` ではなく `（count、（Status）、talking）` が1以上かで判定する（区切りを `、` にする）
- イベント到達時点の固定値であり、処理中に進み具合を追うことはできない（→ `capabilities.md`「実行の途中には手を出せない」）

### 選択肢変数が入る条件

`（選択ＩＤ）（選択ラベル）（選択番号）` が更新されるのは、里々が ID を書き換えた選択肢（`＿` と、ID が `On` でも `script:` でもない `\q`）を選んだときだけ。**更新されないとき、変数は空にならず前回の値がそのまま残る。** 詳細は `internals.md`「選択肢の ID 書き換え」。

### 特殊変数

代入した瞬間に効き、多くは以後のトークにも効き続ける。

| 変数 | 効果 |
|---|---|
| `＄引数区切り追加` `＄引数区切り削除` | 引数の区切り文字を足す・戻す |
| `＄トーク開始時` `＄トーク終了時` | 全トークの前後に文字列を足す |
| `＄選択肢開始時` `＄選択肢終了時` | 選択肢1つずつの前後に文字列を足す |
| `＄スクリプトの一番頭` | 応答の先頭に文字列を足す（1回使われると消える） |
| `＄自動挿入ウェイトタイプ` `＄自動挿入ウェイトの倍率` | 自動ウェイトの種類と長さ（[自動で入るウェイト](#自動で入るウェイト)） |
| `＄文「○○」の重複回避` `＄単語群「○○」の重複回避` | 候補の選び方。「方法、期間」（例：`有効、起動中`）。辞書読込後の `＊OnSatoriLoad` 等で設定する（`＊初期化` では効かずセーブされない） |
| `＄デフォルトサーフェス0` `＄会話時サーフェス戻し` | トーク先頭・戻しサーフェスと挿入有無 |
| `＄喋り間隔` `＄喋り間隔誤差` | ランダムトーク間隔（秒）とばらつき（%）。既定 0（喋らない） |
| `＄次のトーク` `＄次から○回目のトーク` | トークを予約する |
| `＄○○タイマ` `＄全タイマ解除` | 後で `＊○○` を実行する |
| `＄辞書フォルダ` | 読む辞書のフォルダを差し替える（→ `internals.md`「＄辞書フォルダ」） |
| `＄辞書リロード` | `実行` を代入すると、応答後に辞書を読み直す |

- **装飾系（`＄トーク開始時` `＄デフォルトサーフェス0` 等）を条件つきで使うなら、不要になったら空に戻す**
- `＄喋り間隔` の初期値は `satori_conf.txt` の `＊初期化` に書く。セーブデータはその後に読まれるため、利用者の設定変更が維持される
- **タイマの性質**: `OnSecondChange` の回数で数える。1未満を代入すると解除（`＄○○タイマ＝０`）。残りはセーブされ次の起動へ持ち越すため、起動中限りのタイマは `＊OnSatoriClose` で 0 を入れて解除する。`＄全タイマ解除＝実行` は既存辞書のタイマまで消すため使わない

### 起動時に差し替えるなら ＊初期化

`＊初期化` は `satori_conf.txt` に書く。辞書を読む前に実行される。

```
satori_conf.txt → ＊初期化 → セーブデータ → dic*.txt → OnSatoriLoad → OnSatoriBoot
```

`＠初期化` や `dic*.txt` の中に書いても呼ばれず、エラーも出ず無視される。

## 条件式

条件は「定義行のタブ区切り採用条件」「`＞ジャンプ先<TAB>条件`」「`（when,条件,…）`」の3か所に書ける。定義行だけ見て条件なしと判断しない。

| 種類 | 演算子 |
|---|---|
| 四則 | `+` `-` `*` `/` `%`（`＋` `－` `×` `÷` `％`） |
| べき乗 | `^`（`＾`）。Mc201-2 以降 |
| 比較 | `==` `!=` `<` `>` `<=` `>=` |
| 含む・含まない | `=~` `!~`（`＝～` `！～`）。Mc201-2 以降。それより前は常に `0` |
| 論理 | `&&` `||` `!` |

- `^` は二項演算子の中で最強で右結合。単項 `-` はさらに強い（`-2^2` は `4`）
- `=~` `!~` は「左辺が右辺を含む／含まない」（正規表現ではない）。`^` の次に強い
- `<` `>` `<=` `>=` は、どちらかが数値でなければ文字数で比べる（Mc201-1 より前は全角1文字を2と数える）
- `+` `-` `*` は文字列にも働く（`+` つなぎ、`-` 右辺除去、`*` 繰り返し）
- 先に計算させる部分は `（calc,…）` で囲む（`（when,!（calc,（甲）&&（乙））,真,偽）`）

### 真偽の決まり方

括弧展開 → 式計算 → 全角数字を半角化 → 先頭から数値として読めるところまで読む（読めなければ 0）→ 0 以外なら真（C の `strtol`）。

| 書いたもの | 読まれ方 | 判定 |
|---|---|---|
| `0` `00` `-0` | 0 | 偽 |
| `1` `2` `-1` `１` `0１` | 非 0 | 真 |
| `0.5` | `0` で止まる | 偽（小数は書けない） |
| `1あ` | `1` で止まる | 真 |
| `あ1` `あ` 空白だけ | 数値でない | 偽（**空でなければ真ではない**） |

## フロー制御

### 分岐

- `＞ジャンプ先<TAB>条件`: 条件が真ならそのトークへ移動（ジャンプ先が無ければエラーなしで次の行へ進む。内部ログには `not found.` が残る）
- `（when,条件,真,偽）`: 値を返す。文の一部差し替え向け

### 繰り返し

| 書き方 | ループ本文 | カウンタ | 途中で抜ける |
|---|---|---|---|
| `＞` によるジャンプ | 別の `＊` | 自分で変数を用意 | 条件を外す |
| `（loop,名前,回数）` | 別の `＊`／`＠` | `（<名前>カウンタ）`（1始まり） | 不可 |
| `（times,回数[,初期値],本体）` | 引数の中 | `（C0）`（0始まり） | 不可 |
| `（for,開始,終了[,増分],本体）` | 引数の中 | `（C0）`（開始値から） | 不可 |
| `（while,条件[,初期値],本体）` | 引数の中 | `（C0）` | 条件で抜ける |

- **`Ｃ` の番号だけは入れ子の深さ**（`Ｃ０` が内側、`Ｃ１` が1つ外側）：
  ```
  （for,1,2,外（Ｃ０）-（for,3,4,内（Ｃ０）親（Ｃ１）;））
  → 外1-内3親1;内4親1;外2-内3親2;内4親2;
  ```
- `loop` の第1引数に括弧を付けない（`（loop,犬,3）`）。範囲指定 `（loop,名前,開始値,終了値[,増分]）` も可
- `times` / `while` / `for` に括弧で作った区切り文字を渡さない（[展開を遅らせる関数に…](#展開を遅らせる関数に括弧で作った区切り文字を渡さない)）

### 選択肢

| 書き方 | |
|---|---|
| `\q[表示文字,ID,引数…]`<br>`\__q[ID,引数…]…\__q` | さくらスクリプト直接記述。`\__q` は装飾文字や画像ごと押せる |
| `＿選択肢名<TAB>ジャンプ先` | 里々が `\q` に変換。ジャンプ先省略時は選択肢名と同じ |
| `＿選択肢名<TAB>ジャンプ先<TAB>引数…` | 引数つき `\q` に変換（Mc201-11 以降。以前はタブ以降も ID になる） |

| ID | 選んだあと | 引数 | 選択肢変数 |
|---|---|---|---|
| ふつうの文字列 | 里々が `＊その名前` へ飛ばす（`＊OnChoiceSelect` 不要） | `（Ａ０）` 以降（Mc201-11 以降） | 更新される（`\__q` 除く） |
| `On` で始まる | その名前のイベントが直接起きる | `（Ｒ０）` 以降 | 更新されない |

`＊OnChoiceSelect` や `＊OnChoiceSelectEx` を定義すると流れが変わる（`internals.md`「選択肢の ID 書き換え」）。

## 関数

書式は `（関数名,引数1,引数2）`。関数名は半角小文字。日本語名（`単語の追加`、`バイト値` 等）もある。SAORI 呼び出しも同じ形だが、このスキルでは使わない。

### 数字で始まる引数は、渡す前に計算される

**引数が数字か `+` `-` で始まると、関数に渡る前に `calc` で計算される**（全角数字・変数展開後も同様）。

```
＄電話	090-1234-5678
（join,/,（電話）,a）       → -6822/a
（set,日付,2026-09-23）      → 1994
```

計算できない文字列（`a1+2` 等）はそのまま渡る。比較も計算されうる（`2.5>2.4` → `0`）。回避は **`vncall` で変数名を渡す**か、`＄名前<TAB>値` で代入する。`＄SAORI引数の計算<TAB>無効` でも止まるが全体に効くため使わない。

### よく使う関数

代表例で、全量ではない。無いと断定する前に仕様書を引く。

| 用途 | 書式 | 注意 |
|---|---|---|
| 分岐 | `（when,条件,真,偽）` | 選ばれなかった枝を実行しない |
| 多分岐 | `（whenlist,左辺,右辺1,結果1,…,既定値）` | 左辺と右辺を文字連結してから条件式として評価 |
| 計算 | `（calc,式）` | 整数に丸める。未定義変数を扱えない |
| 計算（小数） | `（calc_float,式）` | 比較は式を `(` で始める（[下記](#小数は-calc_float-の中だけで扱う)） |
| 代入 | `（set,名前,値）` | 数字始まりは自動計算。そのまま入れるなら `＄名前<TAB>値` |
| 厳密な比較 | `（equal,A,B）` | 大小文字・全半角を区別 |
| ゆるい比較 | `（compare,A,B）` | どちらも同一視。`compare_head` / `compare_tail`（`_case` で大小区別） |
| 含まれるか | `（count,文字列,検索文字列）` | 出現回数。1以上かで判定 |
| 長さ・切り出し | `（length,…）` `（at,文字列,位置）` `（substr,文字列,開始,長さ）` | 文字単位・0始まり |
| 置換・削除 | `（replace,文,前,後）` `（erase,文,削）` | `_first` で最初の1つだけ |
| 正規表現 | `regex_` で始まる関数 | `count` / `replace` / `split` で足りるならそちら |
| 分割 | `（split,文字列,区切り）`<br>`（split_string,文字列,区切り文字列）` | 戻り値は分割数、中身は `（Ｓ０）`…。**`split` は区切りを1文字ずつ扱う**（`-,` は `-` と `,` の両方で切る）。どちらも既定で空要素を捨てるため、残すなら `（split_string,文,区切り,0,1）`（`0`=上限なし、`1`=空を残す） |
| 連結・反転 | `（join,区切り,文字1,…）` `（reverse,文字）` | |
| 字種変換 | `（zen2han,…）（han2zen,…）（hira2kata,…）（kata2hira,…）` | 英数字をまとめて変換 |
| 判定 | `（is_empty,…）` `（is_digit,…）` `（is_alpha,…）` | 自作変数の有無は `（変数「名前」の存在）` |
| ランダム1つ | `（choice,A,B,C）` | **選ぶ前に全引数を展開する**（処理があると全部走る） |
| 結果を捨てる | `（nop,…）` | 処理目的の関数呼び出しを包む |
| SSP 情報 | `（get_property,プロパティ名,失敗時）` | テスターでは値が取れない |
| 制御文字 | `（バイト値,1）` | 0x01。遅延関数5種の区切りには使えない |
| 単語群操作 | `（単語の追加,単語群名,単語）` | `追加単語の削除` `追加単語の全削除` `合成単語群` |

### call ── ユーザ関数

`（call,名前,引数1,引数2）` で `＠`（単語群）を呼び、引数は `（Ａ０）`…・個数は `（Ａの数）` で受ける。`＊` を呼ぶと改行やスコープが混ざる。

### vncall ── 引数を名前で渡す

引数を「値」ではなく「変数名」で渡し、値中のカンマ類や数字始まり計算で壊れるのを防ぐ。

```
＄入力	あ,い,う
＄区切り	,
（vncall,split,入力,区切り）      「,」で3分割
（vncall,処理,入力）               呼び先の（Ａ０）が「あ,い,う」になる
```

- 対象は `split` 等の区切りが問題になる組み込み関数と自作 `＠` のみ
- 括弧の展開（`（…）`）は防げない
- **遅延評価関数（`when` `whenlist` `times` `for` `while`）を `vncall` で呼ばない**。変数が渡す時点で展開され、全枝実行されてしまう

### 一覧は里々の仕様書から引く

関数の全量は里々の仕様書の `functions/index.md`（内蔵関数）と `ssu/index.md`（ssu 関数）、特殊変数・情報取得変数は `system/index.md` にある（URL は `SKILL.md`「仕様を引く」）。

MCP が使えるなら、里々の仕様書（`satori_docs` 等）に絞って引く：
- 関数の全量：`内蔵関数` と `ssu`（古い MCP では `関数一覧`）を `get_doc` で全文取得
- 1つの関数・変数：名前そのもので検索（`compare_head`、`喋り間隔` 等）。id は版で変わるため都度検索する

## 無い機能と、その代わり

| やりたいこと | 里々での代わり |
|---|---|
| 配列・要素数 | `（split,文字列,区切り）` で `（Ｓ０）`…へ展開（戻り値が分割数）。または `patterns.md`「データを持つ」 |
| 連想配列 | 変数名を動的に組み立てる：`（Ａ（Ａ０））`、`（set,フラグ（Ｃ０）,1）` |
| ローカル変数・スコープ | 無い（すべてグローバルでセーブされる）。`（Ａ０）` や `_` 接頭辞＋使い終わり空代入で管理 |
| `break` / 早期リターン | `for`/`times`/`loop` に `break` は無い。途中脱出が必要なら最初から `while` か `＞` ジャンプで書く |
| イベント・リソース | `＊イベントID`（引数は `（Ｒ０）`…）、`＠リソース名`（`homeurl` 等） |
| SSP 情報・別イベント発火 | `（get_property,…）`、`\![raise,イベント名,引数]` |
| ファイル操作 | ほぼ無い（`mkdir` `lsimg` 程度） |

## 壊れるところ

### 枝を選ぶ関数の多くは、両方の枝を実行する

| 関数 | 選ばれなかった枝 |
|---|---|
| `when` `whenlist` `times` `for` `while` | **実行されない（遅延評価）** |
| `if` `iflist` `unless` `switch` `nswitch` `choice` | **実行される** |

枝に処理（`set` 等）を書くときは必ず `when` / `whenlist` を使う（偽先なら `when` の枝を入れ替え、数値分岐は `whenlist` の右辺を `==1` `==2` にする）。`whenlist` は左辺と右辺を文字連結して条件式として評価するため、演算子の位置を柔軟に書ける：

```
（whenlist,（好感度）,>10,親しい,>5,ふつう,よそよそしい）
（whenlist,（進行度）!,=1,一でない,=2,二でない,どちらでもない）
（whenlist，，（equal,（Ｒ０）,point1），ヒット，外れ）    ＃左辺を空にした例
```

### 展開を遅らせる関数に、括弧で作った区切り文字を渡さない

`when` `whenlist` `times` `for` `while` は、展開前の文字列のうち入れ子括弧の外にある区切り文字を数える。`（バイト値,1）` で区切りを作ると認識されず、`when` は全枝実行、`for`/`times`/`while` は `（Ｃ０）` が空になる。

直接書く `，` などの別区切りにするか、`replace.txt` で別名を定義する。括弧を展開した結果の中にあるカンマ等では割られないが、枝に `\__q[On_X,1]` のようにカンマを直接書くときは区切りを `，` に変える。

```
＠v_カンマ
a,b

（when,1,（v_カンマ）,x）              → a,b
（if,1,（v_カンマ）,x）                → 引数の個数が正しくありません。
（when,1,\__q[On_X,1]ab\__q,x）        → 引数の個数が正しくありません。
（when，1，\__q[On_X,1]ab\__q，x）     → \__q[On_X,1]ab\__q
```

### 引数区切りの誤爆

引数の区切りは最初に現れた1種類に固定されるため、引数や展開結果にその文字が入ると割れる。`、` や `，` へ変えるか、どんな文字も入りうるなら `＄引数区切り追加<TAB>山` のように使われない文字を一時登録する。選択肢を含むトーク全文には 0x01 が必ず入るため、`vncall` で変数名を渡す。

### 外部から来た文字列は、関数に渡した時点で展開される

里々は外部入力（`（Ｒ０）` 等）を変数へ入れる際に括弧を `φ（` で保護するが、**関数に渡した瞬間に保護が外れ、中の全角 `（）` が構文として展開される**。`＄名前<TAB>（Ｒ０）` で受けて変数間を写す間は保たれるが、`replace` 等へ渡した時点で（置換対象が無くても）展開される。

**守り方（順序が重要）**:
1. 外部入力の保存は `＄_inp<TAB>（Ｒ０）`（`set` は数字始まりを計算する、`＝` は展開する）
2. 加工する関数の**引数の区切りを 0x01（`（バイト値,1）`）にする**
3. **最初の置換で全角括弧 `（` `）` を半角へ潰す**（検索側に `φ（` `φ）` を書き、**行末の閉じ括弧は必ず全角 `）` にする**。`\` のエスケープだけでは里々の括弧展開を止められない）

```
＄_inp	（Ｒ０）
＄_out	（replace（バイト値,1）（_inp）（バイト値,1）φ（（バイト値,1）()
＄_out	（replace（バイト値,1）（_out）（バイト値,1）φ）（バイト値,1）)）
＄_out	（replace（バイト値,1）（_out）（バイト値,1）\（バイト値,1）\\）
：（_out）
```

（↑ 入力が `あ,い（乱数0～99）\s[0]` のとき、出力は `あ,い(乱数0～99)\\s[0]` となり乱数は実行されない。無加工でセーブすると `（` `）` は `φ（` として保存されて戻らず、`＃` は行がコメントになって変数ごと消える。）

### カッコの閉じ忘れは、後ろの定義を飲み込む

括弧の中の改行は無視されるため、閉じ忘れた `（`（または末尾を半角 `)` と誤記した行）は次に現れる全角 `）` までを1つの括弧として読み、その間にある `＊` `＠` の行も定義ではなく台詞として表示される。

| 後ろに `）` が | 消える範囲 | 里々の報告 |
|---|---|---|
| ある | 閉じ忘れの定義の次から、`）` のある定義まで | **出ない**（消えた定義を呼ぶと 204 になる） |
| 無い | 閉じ忘れの定義から、ファイルの末尾まで | 出る（ただし `load` は通り、報告はファイル名までで行番号は出ない） |

### 同じ採用条件は1回しか評価されない

同名の定義で採用条件の記述が完全に同じ場合、括弧は1回だけ評価されて全候補で結果が共有される（`＊挨拶<TAB>（乱数0～1）` を2つ並べると両方同じ値になる）。記述自体を変えるか、1つのトーク内で分岐する。

### 数を増やす代入

**未定義の変数を `0` として扱うのは `＄変数＝式` の右辺だけ。** `calc` は未定義で変数名の一部が混ざり（`カウンタ1`）、`set` は式が文字のまま入り、`＄<TAB>` は `（カウンタ）＋１＋１` と伸び続ける。`calc` / `set` で数えるなら `＊初期化` か起動時に初期値 `0` を入れておく。

### 変数・単語群・トークは名前空間を共有する

同名を付けると片方が優先され（例：`＠あいさつ` が `＄あいさつ` を隠す）、どちらも `存在` が 1 を返すため気づきにくい。名前は長めに役割が分かる形で付ける。また **`＠２０` のように裸の数字で定義すると `（２０）` のサーフェス指定が消える**ため絶対に使わない。

内蔵6イベントや日本語読み替えトーク名（`＊起動` `＊終了` 等）の上書き挙動は `internals.md` を参照。

### 自分で作るイベント名は、On_Xxx_Yyy の形にする

選択肢 ID や `\![raise]` を `On` で始めるときは、SHIORI 標準イベント（パスカルケース）との衝突を避けるため `On_Answer` のように `_` で区切る。既存辞書の `OnAnswer` 等は作者が追えなくなるため勝手に改名しない。

### 未知の文字列を == で比べない

外部入力やイベント引数に `-` `!` `<` 等が含まれると条件式として壊れる。定数同士のみ `==` を使い、未知の文字列は `（equal,…）` または `（compare,…）` で比べる。

### 未定義がそのまま表示される

該当しない括弧はエラーにならず文字のまま出る（内部ログには `not found.`）。関数名が正しいのに残る場合は ①`satori.dll` が古く未実装（→ `dialogue.md`「satori.dll が古くて動かないとき」）、または ②再帰・多重ループの深さ制限で展開打ち切り、のどちらかを疑う。

### 整数の範囲

`satori.dll` の版と通す場所で 32bit / 64bit が変わる（→ `internals.md`「整数の範囲」）。範囲外はエラーなしで壊れる。

### 小数は calc_float の中だけで扱う

通常の条件式や `＝` は小数を扱えない（`2.4 > 10` は文字数比較で真になり、`＄平均＝7.0/2` はトークごと 204 になる）。

- 計算も比較も `calc_float` 内で行い、**比較時は式を半角 `(` で始める**（`（when,（calc_float,(2.4)>10）,真,偽）`）
- 整数同士の除算は切り捨てられる（`7.0/2` にする）。結果は小数点以下6桁で丸められる
- 代入は `＄名前<TAB>（calc_float,…）`、表示桁揃えは `（sprintf,%.2f,…）`

## 出力の変換

### 自動で入るウェイト

句読点等の後ろに `\_w[…]` が自動挿入される（`＠` から展開されたセリフにも入る）。値の長さと設定による変動の実測は `internals.md`「自動で入るウェイト」を参照。特定数値を前提にしない。

### ウェイトを止める

| 範囲 | 書き方 |
|---|---|
| その位置だけ | `φ` を置く（`あφ、い`） |
| 囲んだ範囲 | `\_q` 〜 `\_q` で囲む（自動挿入は評価後の組み立て段階で行われるため、この中に入らない） |
| 以後すべて | `＄自動挿入ウェイトタイプ<TAB>無効`、または `＄自動挿入ウェイトの倍率<TAB>0` |

### 自動処理を止める記号 φ

直後の1つだけに対して自動処理を止め、自身は消える（ウェイト自動挿入、`＠` の行末改行、`replace_after.txt` 置換、括弧の展開 `φ（…）`）。続けて止めたいならその数だけ置く（`φ！φ！`）。括弧は開き側 `φ（` だけでよい。

### 壊れるのは第2段階

里々が組み立てた出力に半角 `,` `[` `]` `\` が混ざると SSP がタグ区切りを誤認する。外部文字列をタグ引数へ埋める際は半角記号を全角へ置換する等の手当てが要る。

### よく使うタグ

`\0` `\1`（スコープ）、`\s[N]`（サーフェス）、`\n` `\n[half]`（改行）、`\_w[ms]` `\w1`〜`\w9`（ウェイト）、`\b[-1]`（バルーンを閉じる）、`\e`（スクリプト終端。バルーンを即座に閉じない）、`\q[表示,ID]`（選択肢）、`\_q`〜`\_q`（文字送り0）、`\![raise,イベント名,…]`（別イベント発生）、`\![embed,…]`（別スクリプト埋め込み）、`\_u[0xXXXX]`（Unicode 1文字）、`\f[…]`（フォント・色）。

### さくらスクリプトは大文字と小文字を区別する

`\c`（バルーン消去）と `\C`（先頭に置くと直前バルーンに追記し `\0` へ戻る）、`\_v[ファイル]`（音再生）と `\_V`（再生終了待ち）のように対になるタグが別物として存在する。**対になるタグが無いことを仕様書で確かめてから使う。** `\C` の制約は `display.md`「`\C` ── バルーンを閉じさせない」・`capabilities.md`「実行の途中には手を出せない」。

### さくらスクリプトの寿命

既定はそのスクリプト1回（`\e` まで）。「ゴースト終了まで有効」は説明に明記された例外のみ（`\![set,sticky-window]` `\![set,zorder]` `\![set,alignmenttodesktop]` 等 → `ui_architecture.md`）。
